## Enlaces Amazon

Edite `amazon-links.js` cuando quiera activar botones reales:

```js
window.AMAZON_LINKS = {
  marmol: { ebook: "URL_AMAZON_EBOOK", paper: "URL_AMAZON_PAPEL" },
  oxido:  { ebook: "URL_AMAZON_EBOOK", paper: "URL_AMAZON_PAPEL" },
  piedra: { ebook: "URL_AMAZON_EBOOK", paper: "URL_AMAZON_PAPEL" },
  lodo:   { ebook: "URL_AMAZON_EBOOK", paper: "URL_AMAZON_PAPEL" },
  bronce: { ebook: "URL_AMAZON_EBOOK", paper: "URL_AMAZON_PAPEL" },
  polvo:  { ebook: "URL_AMAZON_EBOOK", paper: "URL_AMAZON_PAPEL" }
};
```

Cuando una URL exista, el botón pasará automáticamente a “Comprar ebook” o “Comprar en papel”.
